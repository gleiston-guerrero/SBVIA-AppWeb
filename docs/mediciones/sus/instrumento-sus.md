**Título del Proyecto:** Evaluación de Usabilidad de SBVIA (Simulador Básico de Valoración y Entrenamiento en Inteligencia Artificial)

## 2. Instrumento de Medición (System Usability Scale - SUS)
*Creado por John Brooke (1986)*

Instrucciones: Para cada una de las siguientes afirmaciones, marque la casilla que mejor describa sus reacciones hacia el sistema hoy. (Escala del 1 = Totalmente en desacuerdo al 5 = Totalmente de acuerdo).

| Ítem | Afirmación | 1 | 2 | 3 | 4 | 5 |
| :--- | :--- | :---: | :---: | :---: | :---: | :---: |
| 1 | Creo que me gustaría utilizar este sistema con frecuencia. | [ ] | [ ] | [ ] | [ ] | [ ] |
| 2 | Encontré el sistema innecesariamente complejo. | [ ] | [ ] | [ ] | [ ] | [ ] |
| 3 | Pensé que el sistema era fácil de usar. | [ ] | [ ] | [ ] | [ ] | [ ] |
| 4 | Creo que necesitaría el apoyo de un técnico para poder utilizar este sistema. | [ ] | [ ] | [ ] | [ ] | [ ] |
| 5 | Encontré que las diversas funciones en este sistema estaban bien integradas. | [ ] | [ ] | [ ] | [ ] | [ ] |
| 6 | Pensé que había demasiada inconsistencia en este sistema. | [ ] | [ ] | [ ] | [ ] | [ ] |
| 7 | Me imagino que la mayoría de las personas aprenderían a utilizar este sistema muy rápidamente. | [ ] | [ ] | [ ] | [ ] | [ ] |
| 8 | Encontré el sistema muy engorroso (awkward) de utilizar. | [ ] | [ ] | [ ] | [ ] | [ ] |
| 9 | Me sentí muy confiado al utilizar el sistema. | [ ] | [ ] | [ ] | [ ] | [ ] |
| 10 | Necesité aprender muchas cosas antes de poder empezar a usar el sistema. | [ ] | [ ] | [ ] | [ ] | [ ] |

---
*Nota metodológica: Para calcular la puntuación, los ítems impares restan 1 de la puntuación del usuario. Los ítems pares se restan de 5. Luego, la suma de las puntuaciones se multiplica por 2.5.*
